# Security policy

## Reporting

Use GitHub private vulnerability reporting for a concern about this repository.
Do not open a public issue containing credentials, personal data, private-source
excerpts, or details that could identify an internal system.

## Scope

This repository contains documentation and fictional JSON examples. It has no
hosted service, authentication system, production connection, deployment, or
customer data. Reports about the undisclosed private implementation are outside
the scope of this public repository.

## Safe examples

Demonstrations must use reserved example domains and invented identities. Do
not submit production exports, logs, screenshots, network details, provider
account identifiers, private routes, or licensed interface material.
