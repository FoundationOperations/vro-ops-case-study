# Screenshot policy

No screenshots or other images are included.

A private production capture can reveal personal data, interface design,
licensed assets, provider details, routes, or operational context even after a
crop or redaction. Those captures are outside this repository's publication
authority.

Any future image must be created entirely from fictional data in a public-only
environment, reviewed for metadata and hidden content, and licensed explicitly.
The written case study must remain complete without it.
